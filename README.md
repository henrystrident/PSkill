# Frame Study · 链接采集

把单篇作品的分享链接粘贴到本地网页，查看可获取的图片和视频，然后选择是否保存。支持小红书、B 站、微博、500px、Instagram。在 `/analyze` 可直接选择已下载图片，分析客观色彩与明暗特征，无需接入大模型。

## 启动

需要 Node.js 18+、[yt-dlp](https://github.com/yt-dlp/yt-dlp) 和 [gallery-dl](https://github.com/mikf/gallery-dl)。在 macOS 上可以运行：

```bash
brew install yt-dlp gallery-dl
cd /Users/nimbuss2000/PSkill
npm start
```

打开 <http://127.0.0.1:4173>。如果端口被占用，可能已有一个实例；也可运行 `PORT=4174 npm start` 并打开 4174 端口。

## 使用方式

1. 粘贴单篇作品链接，或包含链接的整段分享文案。
2. 点击“解析链接”，核对页面列出的图片、视频和封面。
3. 点击“保存全部到本机”。文件存入项目下的 `downloads/平台名-时间标识/`，同时生成 `source.json` 记录来源。

解析时不会自动下载视频。B 站等视频可能较大，保存任务可能需要较长时间；页面会显示当前进度和最终文件链接。图片通常是平台当前提供的尺寸，不保证为拍摄原始文件。

## 支持范围与限制

- 已用实际链接验证：小红书短链的图文（2 张图片）和 B 站短链的视频与封面。小红书两张图片已实际保存成功。
- 500px 已用实际作品链接验证图片解析、预览和保存。该作品元数据标注 2048 × 1367，实际保存的图片为 1024 × 684；元数据尺寸不保证等于下载尺寸。
- 微博、Instagram 已接入 `yt-dlp` / `gallery-dl`，但还需要具体作品链接验证。它们对登录、地区和访问频率可能有限制。
- 工具不会自动读取浏览器 Cookie 或账号。遇到需要登录的作品，会报告无法提取；暂不支持私密内容、个人主页和批量合集。
- 平台网页格式随时可能变化，所列“支持”不代表每个链接都能成功。

## 调色与构图分析

打开 [客观调色分析页](http://127.0.0.1:4173/analyze)，点击已下载图片即可分析；也可拖入本地图片或视频（视频抽取最多 8 帧）。保存新图片后点击“刷新列表”。

- 显示亮度均值、标准差、P5 / P50 / P95 分位数、P95−P5 跨度、近黑与近白占比。
- HSV 饱和度、主要 RGB 色桶及面积占比、12 类色相分布和无明显色相占比。
- 显示亮度和 RGB 直方图；阴影 / 中间调 / 高光的面积、平均 RGB、CIELAB 和饱和度。
- 导出 JSON 报告，包含统计口径、分析尺寸、采样信息和当前画面的全部统计。

统计全部在浏览器执行，页面不检测或调用本地 / 云端模型。图片长边最多缩放到 960 像素，使用画布内 sRGB 像素做二维等距采样；排除完全透明像素，半透明像素按 alpha 加权。亮度使用显示像素加权值 Y′，不是线性光能亮度；Lab 使用 D65 参考白。近黑 / 近白只描述显示像素，不等于原片曝光剪切。分区颜色也受场景和物体本色影响，不能据此还原白平衡、LUT 或 Lightroom 参数。

运行统计回归检查：`npm test`。


### 构图勾线与纯线图

分析页的“之前的南疆构图范本”复用了已有的 14 张手工描线：山脊、前景、湖岸、桥梁和月亮。对应照片按旧脚本的裁切范围导入；复制的范本和归一化线条存于 `composition-references/`，原来的摄影目录文件保留。

选择图片后，在预览下方切换“原图叠加线条 / 纯线图 · 白底黑线”。新图片点击“开始勾线”，选线条类别，沿轮廓逐点点击，再点击“完成这条线”。支持撤销、清空（可撤销恢复）和 PNG / SVG 纯线图导出；JSON 统计报告也包含当前画面的完成线条。三分线不进入纯线图导出。

完成的线条按文件内容和抽帧编号保存在当前浏览器的本地存储；重新导入同一图片可以恢复。线条不会跨浏览器同步，清理网站数据会删除本地保存，请用导出文件留存。范本是之前人工勾好的轮廓。新图片可点击“自动转线稿”，在浏览器本地提取明暗边缘，无需 PS、模型或上传图片。支持调节细节（越高纹理越多）和最短线长（越大碎线越少），调整后再次点击生成；自动结果标为“自动边缘”，不识别山脊或主体类别。生成后自动显示白底黑线图，支持叠加查看、撤销、浏览器本地恢复及 PNG / SVG / JSON 导出。重新生成保留手工线条并替换上次自动结果；未检测到线条时保留现有结果。提取长边最多 720 像素，最多保留 500 条轮廓（优先较长线条），适合照片转线稿，复杂纹理仍可能产生碎线。
