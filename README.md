# Frame Study · 链接采集

把单篇作品的分享链接粘贴到本地网页，查看可获取的图片和视频，然后选择是否保存。支持小红书、B 站、微博、500px、Instagram。旧的本地画面分析页面仍在 `/analyze`，当前工作重点是链接采集。

## 启动

需要 Node.js 18+、[yt-dlp](https://github.com/yt-dlp/yt-dlp) 和 [gallery-dl](https://github.com/mikf/gallery-dl)。在 macOS 上可以运行：

```bash
brew install yt-dlp gallery-dl
cd /Users/nimbuss2000/PSkill
npm start
```

打开 <http://127.0.0.1:4173>。如果端口被占用，可能已有一个实例；也可运行 `PORT=4174 npm start` 并打开 4174 端口。

## 使用方式

1. 粘贴单篇作品链接，或包含链接的整段分享文案。
2. 点击“解析链接”，核对页面列出的图片、视频和封面。
3. 点击“保存全部到本机”。文件存入项目下的 `downloads/平台名-时间标识/`，同时生成 `source.json` 记录来源。

解析时不会自动下载视频。B 站等视频可能较大，保存任务可能需要较长时间；页面会显示当前进度和最终文件链接。图片通常是平台当前提供的尺寸，不保证为拍摄原始文件。

## 支持范围与限制

- 已用实际链接验证：小红书短链的图文（2 张图片）和 B 站短链的视频与封面。小红书两张图片已实际保存成功。
- 微博、500px、Instagram 已接入 `yt-dlp` / `gallery-dl`，但还需要具体作品链接验证。它们对登录、地区和访问频率可能有限制。
- 工具不会自动读取浏览器 Cookie 或账号。遇到需要登录的作品，会报告无法提取；暂不支持私密内容、个人主页和批量合集。
- 平台网页格式随时可能变化，所列“支持”不代表每个链接都能成功。

## 画面分析

旧的 [画面分析页面](http://127.0.0.1:4173/analyze) 可导入本地文件做像素统计。本地视觉模型为可选功能，不影响链接采集。
